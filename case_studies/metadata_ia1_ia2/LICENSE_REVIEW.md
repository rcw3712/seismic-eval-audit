# Distribution boundary for the metadata audit

Checked 28 October 2026. This is a record of the evidence inspected and the packaging decision, not a blanket determination of rights in upstream datasets.

The [official SeisBench repository imprint](https://seisbench.gfz-potsdam.de/imprint/) states that datasets/models have individual, varying licenses. The [SeisBench software license](https://github.com/seisbench/seisbench/blob/e5616ad33c00aba75d5130b44222df46b41e4094/LICENSE) therefore does not authorize redistribution of all dataset metadata. The four inspected dataset adapters provide citations or dataset descriptions but do not explicitly pass a dataset `license` parameter. The [benchmark overview](https://seisbench.readthedocs.io/en/main/pages/data/benchmark_datasets.html) was also inspected; public download availability and bibliographic attribution were not treated as a blanket redistribution grant.

| Metadata | Files | Evidence/decision |
|---|---:|---|
| ETHZ | 1 | Network DOIs supplied; permission for republication of the complete converted metadata table not established in the inspected sources |
| GEOFON | 1 | Adapter citation remains a placeholder; no explicit redistribution grant for this complete benchmark table established |
| Iquique | 1 | Woollam et al. (2019) citation supplied; permission for republication of this converted table not established |
| ISC-EHB Depth Phases | 32 | Primary paper and bulletin attribution available; no uniform redistribution grant for all converted annual tables established |

Consequently, **none of the 35 raw input CSVs is redistributed in the public evidence bundle**. The new extension’s record-level membership, violation and location tables are also excluded; legacy identifier-only ETHZ tables outside this directory remain in both DOI archives, as detailed below. These remain in the local working package and can be regenerated by the scripts after obtaining the exact metadata directly from its official source. `provenance/input_manifest.json` supplies the per-file URL, byte count and SHA-256; `provenance/metadata_license_review.csv` records this decision for every file. If upstream bytes change, acquisition fails hash verification rather than silently substituting a new snapshot. Long-term availability of those exact upstream bytes is not guaranteed by this release.

The public bundle contains original audit scripts, aggregate reports, derived figures, protocols, bibliographic/provenance notes and the unchanged MIT-licensed seismic-eval-audit 0.1.3 wheel. The downloaded SeisBench adapter source files and publisher/author PDFs are excluded; pinned links and hashes identify their provenance. `record_sources.py` can fetch the pinned adapters locally for inspection. No third-party metadata, paper or adapter is relicensed under the project's MIT license.

Network GE DOI 10.14470/TR560404 identifies the GEOFON seismic network, not all networks in the GEOFON benchmark or the full distributed dataset. ETHZ network citations and the Iquique/ISC-EHB paper references are retained in AUDIT_REPORT.md. Dataset attribution is distinct from a redistribution license.

## Scope clarification checked 29 October 2026

The exclusion of row-level outputs applies to the **new case_studies/metadata_ia1_ia2 extension**, not the entire repository or either DOI archive. Both software DOI 10.5281/zenodo.23684054 and evidence DOI 10.5281/zenodo.23758930 contain four legacy identifier-only ETHZ membership tables: three under case_studies/ethz_source/*/membership.csv and one at case_studies/results/ethz_station/membership.csv. Each has 36,743 rows. Their fields are record_id, source_id or station_key, and split; these tables contain no waveforms, coordinates or additional metadata fields. The evidence archive retains these earlier files unchanged outside the extension directory.

Rechecking the [SED waveform-access page](https://www.seismo.ethz.ch/en/knowledge/earthquake-data-and-analysis-tools/waveform-data/), [CH network DOI page](https://networks.seismo.ethz.ch/networks/ch/), [C4 network page](https://networks.seismo.ethz.ch/networks/c4/), [XT network DOI page](https://doi.org/10.12686/alparray/xt_2014), [SED disclaimer](https://www.seismo.ethz.ch/en/service/Disclaimer/) and [SeisBench imprint](https://seisbench.gfz-potsdam.de/imprint/) did not establish a named redistribution license covering the complete converted ETHZ metadata table or derived identifier tables. SED provides open data access and asks for network DOI attribution; this is not treated as a blanket grant to relicense converted tables. The general website disclaimer is not substituted for a dataset-specific license. NOT_ESTABLISHED records a limit in the inspected evidence, not a finding that redistribution is prohibited. Existing archive contents do not themselves establish permission.

The original immutable archives and their manifests have not been rewritten. This clarification is current-branch documentation; it does not retroactively license the archived tables. Upstream confirmation of applicable terms remains unresolved. No third-party data are relicensed as MIT.
